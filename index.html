Analyse des Données

Comprendre comment les données sont collectées, nettoyées et analysées.

1. Collecte de Données (Data Collection)

La qualité de l’analyse dépend directement de la pertinence des sources de données utilisées.

  • Web Scraping : Utilisation d’outils comme BeautifulSoup ou Scrapy pour extraire des informations depuis des sites web.
  • API : Les interfaces de programmation permettent d’accéder aux données de services comme les réseaux sociaux, les services de police ou les plateformes cartographiques.
  • Données ouvertes : Les gouvernements et organisations publient souvent des bases de données accessibles au public.

2. Nettoyage des Données (Data Cleaning)

Avant toute analyse, les données doivent être préparées et nettoyées.

  • Gestion des valeurs manquantes : suppression ou remplacement par des valeurs statistiques.
  • Dédoublonnage : suppression des entrées identiques.
  • Normalisation : uniformisation des formats (dates, noms de lieux, etc.).
  • Détection des anomalies : identification des données aberrantes.

3. Analyse des Données (Data Analysis)

L’analyse permet d’identifier des tendances et de comprendre les relations entre les variables.

  • Statistiques descriptives : moyenne, fréquence, corrélations.
  • Visualisation : graphiques, cartes et heatmaps.
  • Analyse temporelle : étude des variations selon les jours ou les heures.
